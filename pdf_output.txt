課題13-1
 
指定される配列（Array）の要素を、クイックソートアルゴリズムを使って昇順に並び替える関数Array_sortを実装
せよ。
手順
 
1. ピボット選択：配列（リスト）から基準となる要素（ピボット）を1つ選ぶ。
2. 分割：ピボットより小さい要素は左側へ、大きい要素は右側へ移動させ、ピボットをその境界に配置する。
3. 再帰：分割された左側の部分配列と右側の部分配列それぞれに対して、同じ手順（ピボット選択と分割）
を、要素が1つになるまで繰り返す。
4. 全ての部分配列で処理が終わると並び替え終了。
void Array_sort(Array *arr);

課題13-2
 
スタック（Stack）を使って、指定される正の整数nを２進数に変換する関数Decimal_to_binaryを実装せよ。
手順
 
1. 非負整数nを2で割り、その余り（0または1）をスタックにプッシュ（push）する。
2. 商を新たなnとする。
3. nが0になるまで上記1-2を繰り返す。
4. スタックが空になるまでポップ（pop）し、取り出した順に文字('0' or '1')を連結する。
+-----+-----+-----+-----+-----+
|  1  |  2  |  3  |  4  |  5  |
+-----+-----+-----+-----+-----+
int factorial(int n) {
    if (n == 0) return 1;
    return n * factorial(n - 1); // 再帰呼び出し（n! = n × (n-1)!）
}
